# TestApp - iOS IPA Builder via GitHub Actions

Bu proje, macOS runner üzerinde doğrudan derlenip paketlenen tek sayfalık modern bir iOS (SwiftUI) test uygulamasıdır.

## 🚀 IPA Dosyasını İndirme

1. GitHub Repository sayfanızda **Actions** sekmesine gidin.
2. Tamamlanan workflow çalışmasının içine tıklayın.
3. En alttaki **Artifacts** bölümünden `TestApp-iOS-IPA` dosyasını indirin (veya **Releases** sekmesinden doğrudan `.ipa` dosyasını çekin).

## 📱 Cihaza Yükleme
İndirilen `TestApp.ipa` dosyasını:
- **TrollStore** (Jailbreak / CoreTrust bypass - tavsiye edilir)
- **AltStore** (Kendi Apple ID'nizle imzalar)
- **Sideloadly**
- **Scarlet**
üzerinden doğrudan iPhone'unuza aktarıp kurabilirsiniz.
